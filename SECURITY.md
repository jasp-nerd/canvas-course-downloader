# Security

Please report security problems privately, through [GitHub's security advisories](https://github.com/jasp-nerd/canvas-course-downloader/security/advisories/new), not in a public issue. I'll reply within a week.

The extension has no server of its own: it runs in your browser and talks only to your Canvas. Problems worth reporting include anything that sends data elsewhere, runs content from Canvas as code, or uses more access than the [privacy policy](PRIVACY.md) describes.

Only the newest version in the browser stores gets fixes.
